# Brainwave

Landing page for a fictional AI chat product: parallax hero, bento feature grid,
benefits, roadmap and pricing. Built as a design-to-code exercise.

**Live:** https://brainwaveaichat.netlify.app/

## Stack

React - Vite - Tailwind - react-just-parallax - scroll-lock - react-router.

## Run

```bash
git clone https://github.com/ErfanBagheri404/brainwave-react.git
cd brainwave-react
```

```bash
npm install
npm run dev
```

Sections are in `src/components/`; art and icons in `src/assets/`.
